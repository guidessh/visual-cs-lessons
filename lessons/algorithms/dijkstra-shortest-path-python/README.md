# Dijkstra's shortest-path algorithm in Python

Companion code for the Guides.sh lesson **Python Dijkstra's Algorithm Finds
the Shortest Path**.

The implementation uses a min-heap priority queue to find a least-cost route
through a directed graph with non-negative edge weights. It returns the path's
nodes, edge IDs and total cost.

Run the example:

```bash
python dijkstra.py
```

Run the tests:

```bash
python -m unittest -v test_dijkstra.py
```
