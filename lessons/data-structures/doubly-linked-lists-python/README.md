# Doubly linked lists in Python

Companion code for the Guides.sh 3D-animated lesson **Python Doubly Linked
Lists: Every Pointer Update Visualized**.

The implementation exposes both `next` and `prev` references and preserves
the four pointer assignments used when inserting after a known node. It also
demonstrates forward/reverse traversal, boundary updates, deletion, and safe
rejection of foreign or already-deleted nodes.

```bash
python doubly_linked_list.py
python test_doubly_linked_list.py
```

The exact pytest suite displayed and executed in the video is preserved as
`lesson_test_pytest.py`.
