# Singly linked lists in Python

Companion code for the Guides.sh 3D-animated lesson **Linked Lists Explained:
Every Pointer Step Visualized**.

The implementation is deliberately head-only so traversal costs and pointer
updates stay visible. It includes iteration, prepend, append, indexed
insertion, first-match deletion, search, and in-place reversal.

```bash
python singly_linked_list.py
python test_singly_linked_list.py
```

The exact pytest suite displayed and executed in the video is preserved as
`lesson_test_pytest.py`.
