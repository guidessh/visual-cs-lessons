# Adding a lesson

1. Choose the narrowest category under `lessons/`.
2. Create a stable lowercase slug such as `linked-lists-python`.
3. Include the complete source, tests, and a lesson-level `README.md`.
4. Keep the lesson independently runnable from its own directory.
5. Run `python run_all_tests.py` from the repository root.
6. Add the lesson to the root README index.

Do not use names such as `final`, `new`, or `v2`. The folder URL is published in
video descriptions and should remain stable.
